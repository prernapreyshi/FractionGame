# Fraction Game

Interactive fraction learning game with a visual pie model, built using HTML, CSS, and JavaScript.

## Live Demo

- **Live Demo:** https://fraction-game-seven.vercel.app/
- **GitHub Repository:** https://github.com/prernapreyshi/FractionGame

## Features

- 20 levels with increasing difficulty
- Level selection screen
- 3-star rating system
- Timer with bonus points
- Hint button (3 hints per level)
- Achievement badges
- Multiple pie themes (Pizza, Cake, Watermelon, etc.)
- Shows simplified fractions after each level
- Progress saved using Local Storage
- Final score and performance summary
- Three.js celebration animation when a level is completed

## How to Run

Since the project uses JavaScript ES Modules, run it using a local server.

```bash
npx serve .
```

Or open the project with the **Live Server** extension in VS Code.

## Controls

| Action | Key |
|--------|-----|
| Add Piece | → or + |
| Remove Piece | ← or - |
| Hint | Hint Button |
| Next Level | Next Level Button |
| Mute | Speaker Button |
| Restart | Reset Button |
